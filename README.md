# Signature D Website

A responsive luxury website for Signature D.

## Files

- `index.html` — website structure and text
- `styles.css` — full responsive design
- `script.js` — mobile menu, animations, and current year

## Preview on a Google Pixel

1. Extract the ZIP.
2. Install an HTML preview/editor app such as Acode or Spck Editor.
3. Open the project folder.
4. Open `index.html`.
5. Tap Preview.

## Upload to GitHub

Upload all three website files into the root of the `signatured-com` repository.

Then enable GitHub Pages:

1. Open the repository.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select `main` and `/root`.
5. Save.

## Important edits

In `index.html`, replace:

- `hello@signatured.com` with the email you actually use.
- The Instagram and Facebook `#` links with your profile links.
- Placeholder project artwork with your own photographs later.

The contact form currently uses FormSubmit. The first submission triggers a confirmation email before delivery begins.
